# Heading TOC

노트의 제목(`#`)을 모아 로마숫자 목차로 표시하는 옵시디언 플러그인입니다.
프론트매터에 `toc`를 적으면 활성화되며, 목차 모양은 4가지 중에서 선택할 수 있습니다.

```
Ⅰ ·········· 서장
      01 첫 번째 장면
      02 두 번째 장면
Ⅱ ·········· 본문
```

---

## 빠른 시작

노트 첫 줄에 프론트매터를 작성합니다.

ex 1)

```yaml
---
toc: true
---
```


ex 2)

```yaml
---
toc: 3-4
---
```

- `---`는 파일 맨 위에서 시작해야 합니다. 위에 빈 줄이 있으면 인식되지 않습니다.
- `toc:`처럼 값을 비워 두면 동작하지 않습니다. 반드시 **true** 또는 **레벨 값**을 입력해야 합니다.


### 레벨 지정

| 작성 방식 | 의미 |
|---|---|
| `toc: true` | 설정의 기본 레벨 사용 |
| `toc: 3` | `###` 제목만 포함 |
| `toc: 2-3` | `##`은 대제목(Ⅰ Ⅱ Ⅲ), `###`은 소제목(01 02 …) |
| `toc: "2, 4"` | `##`과 `####` 포함 |
| `toc: [2, 3]` | 목록 형태로도 지정 가능 |

가장 높은 레벨이 대제목(로마숫자)이 되며, 그 아래 레벨은 소제목(01, 02 …)이 됩니다.
소제목 번호는 대제목이 바뀔 때마다 01부터 다시 시작합니다.

## 스타일 (`toc-style`)

| 값 | 모양 |
|---|---|
| `banner` | 회색 박스 배너와 목차 (기본값) |
| `text` | `CONTENTS` 고딕체 글자 |
| `list` | 제목 없이 목차만 표시 |
| `biscuit` | 귀여운 비스킷을 클릭해보세요 |

```yaml
---
toc: 2-3
toc-style: biscuit
---
```

## 프론트매터 옵션

| 키 | 설명 | 예시 |
|---|---|---|
| `toc` | 목차 활성화 및 레벨 | `true`, `2-3` |
| `toc-style` | 모양 | `banner`, `text`, `list`, `biscuit` |
| `toc-title` | 제목 문구. `false`이면 제목 줄을 표시하지 않습니다. | `목차` |
| `toc-eyebrow` | 제목 위 작은 문구. `false`이면 숨깁니다. | `"Table of"` |
| `toc-line` | 점선 표시. `false`이면 점선 없는 목록으로 표시합니다. | `false` |
| `toc-roman-align` | 로마숫자 정렬 | `left`, `center`, `right` |
| `toc-start` | 로마숫자 시작 번호 | `4` (Ⅳ부터 시작) |
| `toc-collapsed` | 접힌 상태로 시작 | `true`, `false` |
| `toc-color` | 배너 배경색 | `"#c9a66b"` |
| `toc-text-color` | 배너 글자색 | `"#ffffff"` |
| `toc-image` | 배너 배경 이미지. `false`이면 사용하지 않습니다. | `"[[cover.png]]"` |
| `toc-biscuit-color` | 비스킷 색 | `"#f0cf94"` |
| `toc-biscuit-line` | 비스킷 테두리 및 도트 색 | `"#7a4a21"` |

색상 값은 반드시 따옴표로 감싸야 합니다. YAML에서 `#`는 주석으로 처리되어 값이 누락됩니다.

프론트매터에 작성한 값은 해당 노트에만 적용됩니다. 작성하지 않은 항목은 플러그인 설정값을 따릅니다.

## 기능

### 1. 입력 추천

소스 모드에서 프론트매터에 `toc`, `toc-`, `toc-style:` 등을 입력하면 추천 목록이 표시됩니다.

- 키 추천: 아직 작성하지 않은 `toc-` 키를 설명과 함께 표시합니다.
- 값 추천: 레벨, 스타일, 색상 팔레트 등을 표시합니다.
- 프리셋: `toc:` 뒤에서 선택하면 스타일 줄까지 함께 입력됩니다. 박스 배너, CONTENTS 글자, 비스킷, 목차만, 위키식 목록이 제공됩니다.

설정 → 편집기 → "문서 내 속성"이 "보이기"이면 속성 UI가 입력을 처리하므로 추천 목록이 표시되지 않습니다. "소스"로 변경하거나 아래의 명령어를 사용해야 합니다.

### 2. 목차 위치 지정

기본 위치는 노트 맨 위입니다. 다른 위치에 표시하려면 본문에 다음 코드블록을 작성합니다.

````
```toc
```
````

코드블록이 있으면 맨 위 자동 삽입은 수행되지 않고, 해당 위치에만 표시됩니다.

### 3. 제목에서 목차로 돌아가기

- 읽기 모드: 목차에 포함된 레벨의 제목을 클릭합니다.
- 라이브 프리뷰: Ctrl(Mac은 Cmd)을 누른 채 클릭합니다.

설정에서 비활성화할 수 있습니다.

### 4. 목차 항목 이동

목차의 항목을 클릭하면 해당 제목으로 이동합니다.

## 참고

- `toc-title`을 직접 지정하면 위의 작은 문구(`Table of`)는 기본적으로 숨겨집니다. 함께 표시하려면 `toc-eyebrow`를 별도로 지정해야 합니다.
- `list`, `biscuit` 스타일에는 제목 줄이 없습니다.
